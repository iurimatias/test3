Sheet slicer

Rebuilds assets/atlas.json from the sheets in assets/. Run it from the dev server (python3 serve.py) at /tools/slice.html, then paste the output over the atlas file.

  • Keying — the sheets ship as JPEG with transparency flattened onto a checkerboard. keyBackground in js/sprites.js floods in from the border so interior whites (windmill sails, archery target) survive, and rebuilds soft drop shadows as real alpha.
  • Cells — found from gaps in alpha coverage. A run that swallowed its neighbour is split at its thinnest column until the expected count is met.
  • Captions — on the labelled sheet, the cell is cut at the last quiet gap that still has several rows of content beneath it. Counting rows rather than pixels stops the card's one-pixel bottom border being read as a label.
  • Anchors — the drop shadow's opacity-weighted centroid, sampled in the bottom third. That is the ground-contact point and the steadiest reference across a walk cycle (~12px drift versus ~20px for the bounding box).
  • Unit scale — one scale per strip, derived from head-to-ground height rather than the bounding box, so a tall axe does not shrink the lumberjack. The strips were generated separately and differ in size by up to 45%.
